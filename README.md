# Smart Bank Management System

A console-based Bank Management System developed using Java.

## Features

- Create a new bank account
- View all accounts
- Select an account
- Deposit money
- Withdraw money
- Check account balance
- View account details
- View transaction history
- Search for an account
- Delete an account
- Save account data to a file
- Load saved accounts when the program starts

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- File Handling
- Exception Handling

## Concepts Used

- Classes and Objects
- Constructors
- Encapsulation
- Methods
- ArrayList
- Loops
- Switch Case
- Exception Handling
- FileReader
- FileWriter
- BufferedReader

## Project Structure

SmartBankManagementSystem

    Main.java
    BankAccount.java
    accounts.txt

## How to Run

1. Download or clone the repository.
2. Open the project in VS Code or any Java IDE.
3. Compile the Java files:

javac Main.java BankAccount.java

4. Run the program:

java Main
